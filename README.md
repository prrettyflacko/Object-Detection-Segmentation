# 🤖 Computer Vision Project — Yolo Team

Многофункциональное multipage веб-приложение на базе **Streamlit**, объединяющее современные архитектуры свёрточных нейросетей и трансформеров для решения прикладных задач компьютерного зрения: детекции объектов, маскировки данных и семантической сегментации снимков.

---

## 👥 Наша Команда & Распределение задач

* **Роман**  — **Задание 2:** Разработка и обучение модели детекции опухолей головного мозга (YOLOv11m) на медицинских МРТ-снимках. Проектирование архитектуры Streamlit-приложения и кастомной динамической навигации.
* **Виталий** — **Задание 1:** Разработка модуля детекции лиц с использованием YOLO и алгоритмов последующей автоматической маскировки (Blur) конфиденциальных зон.
* **Совместно** — **Задание 3:** Реализация и обучение архитектуры U-Net для задачи попиксельной семантической сегментации аэрокосмических снимков Земли.

---

## 🛠️ Стек технологий

* **Frontend / UI:** Streamlit (Multipage Architecture)
* **Deep Learning Models:** Ultralytics YOLOv11m, PyTorch (U-Net)
* **Image Processing:** OpenCV, Pillow (PIL)
* **Environment / Package Managers:** Python 3.13, Conda / Pip

---

## 🚀 Функционал веб-сервиса

Согласно техническому заданию, в интерфейсе реализованы следующие ключевые возможности:
1. **Мультизагрузка файлов:** Возможность загружать и обрабатывать сразу пакет МРТ-снимков или фотографий.
2. **Инференс по URL:** Поддержка анализа изображений, загруженных по прямой веб-ссылке.
3. **Интерактивная аналитика моделей:** Выделенные разделы с подробной информацией о процессе обучения (количество эпох, метрики качества $mAP$, кривые Precision-Recall, матрицы ошибок и графики функций потерь).
